# Agentic AI Course Notes

## Git & Setup Commands
- Initialize a repo: `git init`
- Stage all changes: `git add .`
- Commit changes: `git commit -m "your message"`
- Push to main: `git push -u origin main`

## Useful Code Snippets
- uv init - initializes the folder with files like main.py, pyproject.toml
- uv venv - create a virtual environment 
- source .venv/bin/activate - activate the virtual environment

## installing the requirements
- uv add -r requirements.txt 
  (or)
- pip install -r requirements.txt  - install the requirements for the project 
- uv add ipykernel - for jupyter notebook
